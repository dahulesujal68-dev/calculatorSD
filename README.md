# Calculator Web App

A modern, responsive calculator built with HTML, CSS, and JavaScript.

## Features
- Clean dark theme UI
- Basic arithmetic operations (+, −, ×, ÷)
- Percentage support
- Clear and Backspace
- Keyboard support
- Fully responsive

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
